### 📌 About

### HCO NUMBER INFO is a colorful terminal-based phone number metadata viewer.

## This tool helps display public phone metadata such as:

- Validation Status
- Carrier Information
- Country & Region
- Timezone
- Number Type
- Number Formatting
- Export Results
- History System

This tool is designed for educational and informational use only.
